# 🌿 ระบบปฏิทินแม่บ้านรีสอร์ท & ติดตามรอบล้างแอร์ 90 วัน (Resort Keeper)

เว็บแอปพลิเคชันสำหรับแม่บ้านและผู้จัดการรีสอร์ท ออกแบบมาให้ใช้งานง่ายบนมือถือและแท็บเล็ต:
1. **ปฏิทินลงวันเข้าพัก (แตะ 1 ครั้ง = 1 วัน):** เมื่อมีลูกค้าเข้าพักบ้านไหน แม่บ้านแค่แตะปุ่มเพื่อลงสถานะเข้าพัก
2. **ระบบนับวันใช้งานแอร์เพื่อล้างแอร์รอบ 90 วัน (AC Tracker):** ระบบจะนับสะสมเฉพาะ "วันที่ลูกค้าเข้าพักจริง" เมื่อครบ 90 วันจะมีแถบสีแดงเตือนให้ล้างแอร์ทันที พร้อมปุ่ม **"บันทึกล้างแอร์แล้ว"** เพื่อรีเซ็ตกลับเป็น 0 วัน
3. **สมุดบันทึกงานซ่อม & เปลี่ยนอุปกรณ์ (Maintenance Log):** บันทึกว่าวันนี้บ้านไหนเปลี่ยนหลอดไฟ, เปลี่ยนรีโมทแอร์, ซ่อมสายฉีดชำระ พร้อมระบุค่าใช้จ่ายและชื่อช่าง
4. **ออนไลน์เรียลไทม์ (Real-time Sync) ด้วย Supabase:** ข้อมูลซิงค์สดพร้อมกันทุกเครื่อง ไม่ว่าแม่บ้านหรือเจ้าของรีสอร์ทจะเปิดจากเครื่องไหน

## 🚀 ฟังก์ชันเด่นของระบบ

* **โหมดบันทึกรายวันสำหรับแม่บ้าน (Daily Quick Tap):** ปุ่มขนาดใหญ่ กดง่าย สีสันชัดเจน (เขียว = เข้าพัก, เทา = ว่าง)
* **โหมดตารางปฏิทินทั้งเดือน (Monthly Matrix):** ดูภาพรวมการเข้าพักทั้งเดือน แตะแก้ไขย้อนหลังได้ และสรุปยอดวันพักรวม
* **การแจ้งเตือนรอบล้างแอร์ 3 ระดับ:**
  * 🟢 **สีเขียว (0 - 74 วัน):** ใช้งานปกติ
  * 🟡 **สีส้ม (75 - 89 วัน):** ใกล้ครบกำหนด (เตรียมคิวช่าง)
  * 🔴 **สีแดง (90 วันขึ้นไป):** ถึงกำหนดล้างด่วน!
* **ระบบทำงานได้ 2 โหมด:**
  * **โหมดออฟไลน์/ทดลอง (Local Mode):** บันทึกข้อมูลลงในเครื่อง ใช้งานได้ทันทีแม้ยังไม่ได้ต่อฐานข้อมูล
  * **โหมดออนไลน์เรียลไทม์ (Supabase Mode):** อัปเดตสดทันทีระหว่างหลายเครื่อง

## 🛠️ ขั้นตอนการเชื่อมต่อ Supabase (ฐานข้อมูลฟรี)

1. เข้าไปที่ [supabase.com](https://supabase.com) แล้วกด **Start your project** (ฟรี)
2. สร้างโปรเจกต์ใหม่ (ตั้งชื่อโปรเจกต์และรหัสผ่านฐานข้อมูล)
3. ไปที่เมนู **SQL Editor** ทางซ้ายมือ:
   * เปิดไฟล์ `supabase_schema.sql` ในโปรเจกต์นี้
   * คัดลอกโค้ด SQL ทั้งหมดไปวางใน SQL Editor แล้วกดปุ่ม **RUN**
4. ไปที่เมนู **Project Settings > API**:
   * คัดลอก **Project URL**
   * คัดลอก **Project API Keys (anon public)**
5. เปิดหน้าเว็บแอพ คลิกที่ปุ่ม **"⚙️ โหมดทดลอง (Local) / ออนไลน์"** ด้านบนขวา แล้วนำ URL กับ anon key มาวาง แล้วกด **"บันทึกและเปิดใช้งาน"**

## 🌐 ขั้นตอนนำขึ้นออนไลน์ผ่าน GitHub & GitHub Pages

### วิธีที่ 1: Deploy อัตโนมัติผ่าน GitHub Pages (ฟรี 100%)

1. สร้าง Repository ใหม่บน [GitHub.com](https://github.com) (เช่น ตั้งชื่อว่า `resort-keeper`)
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์คำสั่ง:
   ```bash
   git init
   git add .
   git commit -m "feat: initial resort keeper app"
   git branch -M main
   git remote add origin https://github.com/USERNAME/resort-keeper.git
   git push -u origin main
   ```
3. บน GitHub ไปที่หน้า Repository ของคุณ:
   * คลิกที่แถบ **Settings** > **Pages**
   * ที่หัวข้อ **Build and deployment > Source** ให้เลือกเปลี่ยนเป็น **GitHub Actions**
4. GitHub Actions จะเริ่ม Build และ Deploy เว็บแอพให้โดยอัตโนมัติ 
5. รอ 1–2 นาที จะได้รับลิงก์เว็บไซต์ออนไลน์ เช่น `https://USERNAME.github.io/resort-keeper/` สามารถส่งลิงก์ให้แม่บ้านเปิดบนมือถือได้ทันที!

### วิธีที่ 2: Deploy ผ่าน Vercel หรือ Netlify
* สามารถเชื่อมต่อกับ GitHub Repository นี้บน [Vercel](https://vercel.com) แล้วกด Deploy ได้ทันทีโดยไม่ต้องตั้งค่าเพิ่มเติม
